# Rododendron
### Лёгкі настольны VPN‑кліент: мінімум лішняга, максімум карысці.
> На дадзены момант у бэце


> Скрыншоты
![Main screen full](.github/assets/rododendronscrinmain.png)


### Фішкі
- Маршрутызацыя: правілы па **праграмах** і **даменах**.
- 3 мовы інтэрфейсу: Руская · Беларуская · Англійская.
- **Снегапад** =).


### Платформа
> Пакуль падтрымліваецца толькі Windows.
>> У бліжэйшай будучыні з’явяцца і іншыя платформы.


### Як карыстацца
1. Адкрый **Налады** → дадай канфіг.
2. У галоўным акне націсні **Уключыць**.
3. Правілы маршрутызацыі — ва ўкладцы **Маршрутызацыя**.


### Калі нешта не працуе
> Націсні **«Перазапусціць VPN»** унізе — у большасці выпадкаў дапамагае.
