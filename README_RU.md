# Rododendron
### Лёгкий десктопный VPN‑клиент: минимум лишнего, максимум пользы.
> На текущий момент находится в бете

> Скриншоты
![Main screen full](.github/assets/rododendronscrinmain.png)

### Фишки
- Маршрутизация: правила по **приложениям** и **доменам**.
- 3 языка интерфейса: Русский · Беларуский · Английский.
- **Снегопад** =).

### Платформа
>Пока поддерживается только Windows.
>> В ближайшем будущем появятся остальные платформы.

### Как пользоваться
1. Открой **Настройки** → добавь конфиг.
2. В главном окне нажми **Включить**.
3. Правила маршрутизации — во вкладке **Маршрутизация**.

### Если что-то не работает
>Нажми **«Перезапустить VPN»** снизу — в большинстве случаев помогает.
