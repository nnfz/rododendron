# Rododendron
### A lightweight desktop VPN client: minimal clutter, maximum usefulness.
> Currently in beta


![Main screen full](.github/assets/rododendronscrinmain.png)


### Features
- Routing: rules by **applications** and **domains**.
- 3 UI languages: Russian · Belarusian · English.
- **Snowfall** =).


### Platform
> Currently only Windows is supported.
>> Other platforms are coming soon.


### How to use
1. Open **Settings** → add a config.
2. In the main window, click **Enable**.
3. Routing rules are in the **Routing** tab.


### If something doesn’t work
> Click **“Restart VPN”** at the bottom — it helps in most cases.
